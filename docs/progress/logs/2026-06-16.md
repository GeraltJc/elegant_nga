## Decisions / ADR

- 暂不接入 Logstash。
- 当前采用 Laravel Artisan 命令将 MySQL 数据写入 Elasticsearch。
- 当前搜索索引分为：
  - `nga_threads`
  - `nga_posts`
- 当前中文搜索先使用 Elasticsearch 默认能力，满足基础搜索与高亮验收。
- 中文分词优化后续再处理，不阻塞搜索功能闭环。
- nginx / php-fpm 启动稳定性采用 healthcheck + depends_on service_healthy 的方式解决。
- PHP healthcheck 使用 `php-fpm -t` 与 `nc -z 127.0.0.1 9000`，检查 php-fpm 配置和端口可连接性。

## Risks / Blockers

- 当前中文分词只是基础可用，搜索“救赎”时高亮会拆成单字。
- `search:reindex --fresh` 会删除并重建 Elasticsearch 索引，开发验收适合使用，但生产环境需要更谨慎。
- 当前没有自动增量同步，MySQL 数据变化后需要手动或定时执行同步逻辑。
- `docker compose restart php nginx` 仍不如 `docker compose up -d php nginx` 稳妥，后续开发推荐使用 `up -d`。
